Client Terms & Policies

These are the terms AXIS Digital Engineering operates under for every client project — domain handling, revisions, payment structure, post-launch support, and data ownership. If anything here is unclear, ask before signing off on a project.

EFFECTIVE 2026 — SUBJECT TO UPDATE PER PROJECT AGREEMENT
01

Exclusive Domain Policy

We exclusively manage and host domains registered through Namecheap. Any client-supplied domain hosted on alternative external registrars (such as Bluehost, GoDaddy, or Hostinger) incurs an additional external domain integration fee.

02

Third-Party Platform Liability

AXIS Digital Engineering takes zero responsibility for outages, propagation delays, billing lapses, or security locks originating from third-party registrars. If an external platform experiences technical failures or expired registry status, hosting deployment is paused immediately, requiring the client to manage the infrastructure independently.

03

Included Revision Rounds

Every project package includes a defined set of revision rounds (e.g., 2 major rounds) during the active development phase. Feedback must be consolidated within a set timeframe to ensure smooth project momentum and prevent indefinite scope creep.

04

Post-Launch Warranty Window

All projects include a 14-day bug-fixing warranty post-launch. This covers functional bugs, broken styling, or deployment errors directly related to our initial code, giving clients complete peace of mind after going live.

05

Transparent Milestone Payments

Billing is structured into predictable phases (typically a 50% upfront deposit to secure the build slot and the remaining 50% upon final client approval prior to live deployment), ensuring financial clarity for both parties.

06

Dedicated Handoff & Training

Projects conclude with a clean documentation guide or a short recorded walkthrough video demonstrating how to manage the platform, use the invoice system, or update content independently.

07

Custom Software Data Ownership

For web apps and internal invoice systems, all generated business data, customer databases, and application logic belong exclusively to the client, secured behind isolated database rules and secure authentication architectures.

08

System Integration Boundaries

For tools requiring third-party APIs (such as payment gateways, email services, or external software), API changes, rate limits, or service outages enforced by those external providers fall outside our direct liability and maintenance scope.

Questions about any of these terms? Reach out before starting a project and we'll walk through it together.
